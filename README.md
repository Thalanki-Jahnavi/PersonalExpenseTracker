# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a Java-based application designed to help users manage their personal finances by recording income and expenses and tracking their remaining balance.

## Features
- Record income and expenses
- View transaction history
- Calculate total income and expenses
- Track the remaining balance
- Organize financial transactions

## Technologies Used
- Java
- JDBC
- MySQL
- SQL

## How It Works
The application allows users to enter income and expense transactions. It stores transaction details in a database and calculates the remaining balance based on the recorded transactions.

## Future Enhancements
- Monthly expense reports
- Expense category management
- Improved user interface
- Budget tracking
